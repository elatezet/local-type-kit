Many brand fonts may not be uploaded to a shared font service. Local Type Kit works with them across the whole file, including text styles and instance overrides, and sends nothing over the network.

See what the file uses

Lists every font in text layers and in local text styles, and marks the ones that are not installed on this machine.

Swap a font everywhere

Loose text, components, instance overrides, local styles and mixed text runs. Components change first, so instances keep only the overrides they really have. A preview shows the counts first.

Build text styles from variables

Creates or updates text styles from a variable collection and binds family, size and line height to the variables.

Attach loose text to styles

Gives loose text the one local style that matches it exactly. If more than one fits, the text stays as it is and goes on a list.

Install Questions

Free and open source under the MIT license.

Also runs without the window

The same functions work from a script through Figma's Plugin API. Set one flag, load code.js and call scan, replaceFonts, stylesFromVariables or assignStyles. That helps when a script or an assistant prepares a file instead of a person. The README shows how.

Two files, no build step

  1. Download or clone the repository on GitHub.
  2. In the Figma desktop app, choose Plugins → Development → Import plugin from manifest and pick manifest.json.
  3. Open a design file and run Plugins → Development → Local Type Kit.

Questions

Does the plugin send anything over the network?

No. The manifest allows no network domain at all, and nothing is uploaded. Fonts load from your machine through the desktop app.

Can I undo a run?

Yes. Every change shows a preview first, and every run is one undo step.

What happens to text whose font is bound to a variable?

It is skipped and listed. The plugin never removes a variable binding.

Where is the setup stored?

In the Figma file itself. The next person who opens the plugin there runs the same configuration.

Why does a colleague still see the font as missing?

That limit belongs to Figma: the font has to be installed on every machine that edits the file, and no plugin changes that. Local Type Kit shows you where it is missing. In the browser, Figma's font installer is needed as well.

Does it help with exports that Figma renders on its servers?

No. Figma's servers only know fonts that an admin uploaded to the organization, which needs the Organization or Enterprise plan. Video exports and other renders on Figma's side fall back to another font. Export from the desktop app instead, or upload the font as a shared font if its license allows that.

What does it cost?

Nothing. It is open source under the MIT license: two files, no build step, no dependencies.
