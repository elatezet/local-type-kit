Figma plugin · open source

Your typeface stays on your machine.

Licensed brand fonts often may not be uploaded to a shared font service. The Figma desktop app can still use them. Local Type Kit does the repetitive work around them across a whole file.

No network access Nothing uploaded MIT license

What it does

Four tabs, in the order you need them.

01 · Fonts

See what the file uses

Lists every font in text layers and in local text styles, and marks the ones that are not installed on this machine.

02 · Replace

Swap a font everywhere

Loose text, components, instance overrides, local styles and mixed text runs. Components change before their instances, so instances keep only the overrides they really have. A preview shows the counts first.

03 · Styles

Build text styles from variables

Creates or updates text styles from a variable collection and binds family, size and line height to the variables.

04 · Assign

Attach loose text to styles

Gives loose text the one local style that matches its family, weight, size and line height exactly. If more than one fits, the text stays as it is and goes on a list.

Safe by design

It changes your file and nothing else.

  • No network access. The manifest allows no domains.
  • Nothing is uploaded. Fonts load from your machine through the desktop app.
  • Every change has a preview, and every run is one undo step.
  • Text whose font family is bound to a variable is skipped and listed, never unbound.
  • The setup is stored in the file, so the next person runs the same configuration.

One limit

The font has to be on every machine.

This limit belongs to Figma. People without the font installed see it as missing, and no plugin changes that. Local Type Kit shows you where that is the case. In the browser, Figma's font installer is needed as well.

Install

Two files, no build step.

  1. Download or clone the repository.
  2. In the Figma desktop app: Plugins → Development → Import plugin from manifest, and pick manifest.json.
  3. Open a design file and run Plugins → Development → Local Type Kit.

The Figma Community listing and the GitHub repository follow with the first release.
