Every font in use at a glance

Local Type Kit finds every font used in text and styles. Missing fonts are detected and marked automatically.

Swap fonts everywhere

Local Type Kit swaps a font across the whole file, in components, instances and styles. The preview shows what changes before anything does.

Text styles straight from variables

Local Type Kit turns your typography variables into text styles. Size, line height and family stay bound to the variables.

Give loose text its style

Text without a style gets the matching style automatically. If more than one fits, the text stays as it is and goes on a list.

MCP ready

Claude, ChatGPT, Cursor, Gemini or Grok use Local Type Kit right in your file through Figma's MCP server. Checking fonts, building styles and attaching loose text works straight from the chat. Only fonts that live on your computer alone need the plugin in the desktop app.

Claude ChatGPT Cursor Gemini Grok

The buttons copy the matching prompt. Claude, ChatGPT and Cursor open with the prompt filled in; in Gemini and Grok you paste it yourself. Your assistant needs to be connected to Figma's MCP server.

Questions

Does the plugin send data over the network?

No. Local Type Kit has no network access and uploads nothing. Your fonts stay on your computer.

Can I undo changes?

Yes. A single undo takes back a whole run.

What happens to text whose font is bound to a variable?

Local Type Kit leaves that text as it is and shows it to you in a list. The binding to the variable stays.

Where is the setup saved?

Right in the Figma file. Whoever opens the plugin there next works with the same setup.

Why does a colleague still see the font as missing?

Every computer that edits the file needs the font. No plugin can change that. Local Type Kit does show you where it is missing.

Does the plugin help with exports that Figma renders on its servers?

No. Figma's servers only know fonts an admin uploaded for the organization. That needs the Organization or Enterprise plan. In that case, simply export from the desktop app.

Can I install the plugin without Figma Community?

Yes. Download the repository from GitHub. In the Figma desktop app, choose Plugins → Development → Import plugin from manifest and then manifest.json.

What does Local Type Kit cost?

Nothing. The plugin is free and open source under the MIT license.
