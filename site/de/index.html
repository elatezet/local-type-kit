Features

01 · Fonts

Sehen, was die Datei benutzt

Listet jede Schrift in Textebenen und in lokalen Textstilen und markiert die, die auf diesem Rechner fehlen.

02 · Replace

Eine Schrift überall tauschen

Loser Text, Komponenten, Abweichungen in Instanzen, lokale Stile und gemischte Textläufe. Komponenten kommen zuerst dran, damit Instanzen nur ihre eigenen Abweichungen behalten. Eine Vorschau zeigt vorher die Zahlen.

03 · Styles

Textstile aus Variablen bauen

Legt Textstile aus einer Variablensammlung an oder aktualisiert sie und bindet Familie, Größe und Zeilenhöhe an die Variablen.

04 · Assign

Losen Text an Stile hängen

Gibt losem Text den einen lokalen Stil, der genau passt. Passen mehrere, bleibt der Text, wie er ist, und landet auf einer Liste.

Zwei Dateien, kein Build

  1. Repository herunterladen oder klonen.
  2. In der Figma-Desktop-App Plugins → Development → Import plugin from manifest wählen und manifest.json auswählen.
  3. Eine Designdatei öffnen und Plugins → Development → Local Type Kit starten.

Fragen

Schickt das Plugin etwas übers Netz?

Nein. Das Manifest erlaubt keine einzige Domain, und nichts wird hochgeladen. Die Schriften kommen über die Desktop-App von deinem Rechner.

Kann ich einen Lauf rückgängig machen?

Ja. Jede Änderung zeigt vorher eine Vorschau, und jeder Lauf ist ein einziger Rückgängig-Schritt.

Was passiert mit Text, dessen Schrift an eine Variable gebunden ist?

Er wird übersprungen und aufgelistet. Das Plugin löst nie eine Bindung an eine Variable.

Wo liegt die Einrichtung?

In der Figma-Datei selbst. Wer das Plugin dort als Nächstes öffnet, arbeitet mit derselben Konfiguration.

Warum sieht eine Kollegin die Schrift trotzdem als fehlend?

Die Grenze liegt bei Figma: Die Schrift muss auf jedem Rechner installiert sein, der die Datei bearbeitet, und kein Plugin ändert das. Local Type Kit zeigt dir, wo sie fehlt. Im Browser braucht es zusätzlich Figmas Font-Installer.

Was kostet es?

Nichts. Es ist quelloffen unter MIT-Lizenz, zwei Dateien ohne Build und ohne Abhängigkeiten.
