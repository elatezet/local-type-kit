Das ist das echte Plugin mit einer Beispieldatei. Probier es einfach aus.

Alle verwendeten Schriften auf einen Blick

Local Type Kit erfasst alle verwendeten Schriften in Text und Stilen. Fehlende Schriften werden automatisch erkannt und markiert.

Schriften einfach überall tauschen

Local Type Kit tauscht eine Schrift in der ganzen Datei, auch in Komponenten, Instanzen und Stilen. Die Vorschau zeigt vorher, was sich ändert.

Textstile direkt aus Variablen

Local Type Kit macht aus deinen Typografie-Variablen fertige Textstile. Größe, Zeilenhöhe und Familie bleiben an die Variablen gebunden.

Losem Text den passenden Stil geben

Text ohne Stil bekommt automatisch den passenden Stil. Passen mehrere, bleibt der Text, wie er ist, und landet auf einer Liste.

Installieren Fragen

Kostenlos und quelloffen unter MIT-Lizenz.

Funktioniert auch mit deinem KI-Assistenten

Claude, ChatGPT, Cursor, Gemini oder Grok nutzen Local Type Kit über Figmas MCP-Server direkt in deiner Datei. Schriften prüfen, Stile bauen und losen Text zuordnen geht damit direkt aus dem Chat. Nur Schriften, die allein auf deinem Rechner liegen, brauchen das Plugin in der Desktop-App.

Claude ChatGPT Cursor Gemini Grok

Jeder Knopf kopiert den Prompt. Claude, ChatGPT und Cursor öffnen sich direkt mit dem Prompt, bei Gemini und Grok fügst du ihn selbst ein. Dein Assistent muss dafür mit Figmas MCP-Server verbunden sein.

Fragen

Schickt das Plugin Daten übers Netz?

Nein. Local Type Kit hat keinen Netzzugang und lädt nichts hoch. Deine Schriften bleiben auf deinem Rechner.

Kann ich Änderungen rückgängig machen?

Ja. Jeder Durchlauf lässt sich mit einem einzigen Rückgängig zurücknehmen.

Was passiert mit Text, dessen Schrift an eine Variable gebunden ist?

Local Type Kit lässt solchen Text unverändert und zeigt ihn dir in einer Liste. Die Bindung an die Variable bleibt erhalten.

Wo wird die Einrichtung gespeichert?

Direkt in der Figma File. Wer das Plugin dort als Nächstes öffnet, arbeitet mit derselben Einrichtung.

Warum sieht eine Kollegin die Schrift trotzdem als fehlend?

Jeder Rechner, auf dem die Datei bearbeitet wird, braucht die Schrift. Das kann kein Plugin ändern. Local Type Kit zeigt dir aber, wo sie fehlt.

Hilft das Plugin bei Exporten, die Figma auf seinen Servern rendert?

Nein. Figmas Server kennen nur Schriften, die ein Admin für die Organisation hochgeladen hat. Das geht nur im Organization- oder Enterprise-Tarif. Exportiere in dem Fall einfach aus der Desktop-App.

Kann ich das Plugin auch ohne Figma Community installieren?

Ja. Lade das Repository von GitHub herunter. In der Figma-Desktop-App wählst du dann Plugins → Entwicklung → Plugin aus Manifest importieren und anschließend manifest.json.

Was kostet Local Type Kit?

Nichts. Das Plugin ist kostenlos und quelloffen unter MIT-Lizenz.
